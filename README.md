# Arduino-MAX30102-PPG-signal
Microprocessors college project using Arduino and MAX30102 sensor to output the ppg signal
##Project Status and Overview:
* status: In progress. I still have not gotten it checked by my professor but the code executes properly and produces a waveform.
* Next step: I have to go get it checked and verified by my professor.

## Methodology and contributions:
* Code implementation: I generated and iterated on this code using AI assistance. I faced many problems trying to output a proper waveform and after multiple attempts with AI assistance, I was able to conclude with this code as it produced the best waveform among other codes. The waveform was closest to the PPG waveform. The code is not perfect. The waveform takes a minute or two to form. And the BPM takes a minute or two to show in the serial monitor.
* Hardware Part: I connected the hardware part using Arduino, MAX30102 sensor and breadboard.
